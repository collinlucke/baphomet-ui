# Baphy

Simply put, Baphy is a movie ranking app. In the Arena, you are shown two movies and you pick the one you think is better. Those votes become a community score.

The app is a React and TypeScript frontend, built with Vite and styled with Emotion. It talks to a GraphQL API through Apollo Client, and the interface is built from [athameui](https://github.com/collinlucke/athameui). Development was done in Cursor.

[Check out the live app](https://baphy.onrender.com)
